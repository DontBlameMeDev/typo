# Typo 0.3.0

## What's new

- **Swipe right to favorite a note or folder.** A favorite shows a star and
  sorts above the rest of its folder. The left swipe still trashes. A gesture
  locks to one side for its whole drag, so a swipe cannot flip between trash
  and favorite halfway. Favorites are kept per vault and follow notes and
  folders when they move.
- **Swipes run on the UI thread.** The drag, spring, and haptics now use
  `react-native-gesture-handler` and `react-native-reanimated` instead of the
  JS bridge, and the action pane only mounts while a swipe is in progress.

## Performance

- **Search is much faster.** A content search over 1,000 notes went from
  286 ms to 32 ms on the host, a literal search from 174 ms to 4.3 ms, and a
  fuzzy search from 169 ms to 11 ms. Syntax highlighting, saving, and the
  content fingerprint also do less work per keystroke.
- **Typing no longer sends the whole note across the WebView bridge.** A
  single keystroke in a 10,000-line note sends 101 bytes instead of 358 KB,
  and the host stops keeping 50 full copies of the note for echo suppression.
- **Autosave no longer reindexes the vault.** A content search open during an
  autosave now patches only the notes that changed.

## Fixes

- The library keeps its results on screen while a search runs, so typing no
  longer flashes an empty list between keystrokes.
- Notes with a current `out/hashes` sidecar are no longer recompiled. Synced
  vaults stop reporting compile errors for notes that already have a PDF, and
  a PDF that is already current opens without a compile.

## Install

Download `typo-0.3.0.apk` below and open it. Typo needs Android 7.0 or newer
and a 64-bit phone. The APK includes `arm64-v8a` and `x86_64`.

Updates install over 0.2.0 without an uninstall.

**Full changelog**: https://github.com/DontBlameMeDev/typo/compare/v0.2.0...v0.3.0

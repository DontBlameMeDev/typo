# Typo 0.2.0

## What's new

- **Notes save themselves.** Editing writes the note 600 ms after the last
  keystroke, so the editor no longer has a Save button. Leaving a note waits
  for the final write. If that write fails, the note closes and the library
  reports the failure for that note.
- **Trash and move folders.** Swipe a folder to trash it, or swipe further to
  confirm. Long-press a folder to move it. The whole tree is copied and
  verified before the source is removed, and the notes inside keep their
  paths.
- **Search modes that stay out of the way.** The Names, Content, and
  Everywhere modes show up when the search field is focused and fade away
  when it is not, so the library keeps its room for notes.

## Fixes

- One unreadable note no longer empties the library. The read is retried
  once, then the note is skipped and listed in a notice.
- Back gestures work on a note again on Android 13 to 15.
- Note titles truncate to one line with an ellipsis, like folder rows.
- The vault pill shows a swap icon, which matches what the button does.
- The dark splash keeps its fold visible against the launch background.
- The about sheet drops its redundant details header.

## Install

Download `typo-0.2.0.apk` below and open it. Typo needs Android 7.0 or newer
and a 64-bit phone. The APK includes `arm64-v8a` and `x86_64`.

Updates install over 0.1.0 without an uninstall.
